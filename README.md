## 🧠 About Me

I exist at a crossroads that most professionals never reach — the space where **generative AI filmmaking** meets **cybersecurity intelligence**. While the world treats these as separate universes, I've spent years proving they share the same core logic: both demand pattern recognition under pressure, adversarial thinking, and the ability to architect outcomes from ambiguity.

By day, I architect AI-driven visual narratives — producing cinematic content with tools that most creatives haven't learned to wield. By discipline, I analyze attack surfaces, track threat actors, and build security automation that preempts breaches before they materialize.

- 🎓 **B.Eng. Electronics & Computer Engineering** — Nnamdi Azikiwe University
- 🌍 **Based in** Awka, Anambra State, Nigeria
- 🔭 **Current Pursuit:** Merging generative AI pipelines with security automation systems
- 🧩 **Unique Edge:** Web3/blockchain community expertise spanning 4+ protocol ecosystems
- 💡 **Philosophy:** Security is a creative act. Storytelling is a precision science.
